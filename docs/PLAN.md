# 实施计划

1. 数据和业务：建立实体与 JDBC 表，先写登录/权限/库存/查询/持久化/问答测试，确认缺失，再实现 DAO、Service。验证：mvn test。
2. 交互界面：Swing 登录注册、菜单和侧栏、概览、药材 CRUD 和详情、库存、用户、日志、个人资料、问答；使用 SwingWorker 执行后台任务。
3. 运行交付：打包可执行 JAR，加入 Java 启动器，启动真实窗口并用 Java Robot 验证登录和导航，保存检查截图；说明 MySQL 配置和演示账户。

重点检查：访客绕过 UI 写入、负库存和并发出库、重复编号/账号、资料修改后会话、数据库故障的明确反馈。正式 MySQL 必须有可用账户后才能验收。
