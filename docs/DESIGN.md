# 中药材智能管理平台基础版

依据用户提供的期末实验报告，采用 Java 17 + Swing 原生桌面界面，JDBC 数据访问，view/controller/model/service/dao/util 分包。无需浏览器，不使用 HTML、JavaScript、Vue、CSS 或 FXML。

正式数据库为 MySQL 8.0；为保证首次运行可预览，另提供 H2 文件数据库演示模式，两种模式使用同一套 JDBC DAO 和建表逻辑。MySQL 连接失败时明确报错，不静默切换数据库。

用户模块：注册默认访客，MD5 按作业要求保存，登录验证码、角色权限、登录日志、个人资料与密码修改。管理员管理用户；药师和管理员维护药材；访客只读药材并使用问答。所有写操作在 service 再次校验权限。

药材模块：编号、名称、分类、产地、库存、单价、功效、用法、储存条件、预警阈值；多条件筛选、增删改查、详情、原子入出库、库存流水和预警。货币使用 BigDecimal，数量使用整数。

问答模块：仅按药材名称和功效关键词匹配教学知识库，不接入远程 AI，按当前用户持久化问答历史，不提供诊断或处方。

界面采用侧栏导航、顶部身份信息、概览统计、药材表格、问答、用户、日志和个人资料。Java 绘制界面装饰，无需图片资源。

选型：Swing 比 JavaFX 更符合指定技术和现有 JDK，无需额外 UI 运行时。先完成可检查的基础版，后续根据用户反馈优化。
