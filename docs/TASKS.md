# 可并行开发任务清单

新 AI 窗口可直接从这里选择任务。选择前先阅读 `AI_HANDOFF.md`。并行任务必须避免同时修改同一个文件；若任务涉及 `Platform.java`、`MainFrame.java` 或 `pom.xml`，应由一个窗口负责，其他窗口只提供建议或修改独立文件。

## 当前优先级

### P0 运行与稳定性

- [ ] 修复和补充 MySQL 版本差异验证。
- [ ] 增加数据库连接失败、空结果和重复初始化的界面验证。
- [ ] 将真实桌面启动检查整理为可重复的手工验收步骤。

### P1 课程功能增强

- [ ] 增加药材分类管理，而不是固定使用 `Platform.CATEGORIES`。
- [ ] 增加分页或更强的多条件查询。
- [ ] 增加用户启用/禁用状态和登录失败次数。
- [ ] 增加问答关键词维护界面。
- [ ] 增加库存入出库确认和操作备注必填策略。

### P2 体验优化

- [ ] 优化工作台统计卡片和低库存视觉提示。
- [ ] 增加导出 CSV 或实验报告截图辅助功能；导出仍使用 Java，不引入前端语言。
- [ ] 增加主题色、字体大小和窗口布局适配。
- [ ] 增加实验报告中的步骤说明和截图。

## 独立任务建议

| 任务 | 主要文件 | 不应修改 | 验收 |
|---|---|---|---|
| 数据库升级 | `Database.java`、`DATABASE.md` | Swing 页面 | `mvn test` + 初始化验证 |
| 业务规则 | `Platform.java`、`PlatformTest.java` | 视图布局 | 新测试红绿循环 + 全量测试 |
| 药材页面 | `MedicinalPanel.java`、`Theme.java` | 数据库 SQL | 编译、手工 CRUD 验证 |
| 问答页面 | `ChatPanel.java` | 用户管理页面 | 问答和历史手工验证 |
| 用户页面 | `MainFrame.java` | `MedicinalPanel.java` | 三种角色权限验证 |
| 文档和实验报告 | `docs/`、`README.md` | 生产代码 | 文档链接和命令可执行 |

## 任务交接格式

完成一个并行任务后，向主窗口返回：

```text
任务：...
修改文件：...
行为变化：...
验证命令：...
验证结果：...
未处理问题：...
```

不要只回复“完成”，主窗口必须能据此检查实际结果。
